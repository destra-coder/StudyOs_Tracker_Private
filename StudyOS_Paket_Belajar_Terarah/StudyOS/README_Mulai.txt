STUDYOS — WEB TRACKER + LANGKAH BELAJAR TERARAH

MULAI CEPAT
1. Extract StudyOS_Web_Tracker_Terarah.zip.
2. Buka index.html untuk memakai tracker secara lokal.
3. Untuk memasang seperti aplikasi di HP/laptop dan mengaktifkan cache/offline, upload SELURUH isi folder (index.html, manifest.webmanifest, service-worker.js, assets/) ke hosting HTTPS.
4. Buka URL hosting di Chrome/Edge. Pilih Install app / Add to Home Screen.

- Senin: AI & Automation. Selasa: Web Development. Rabu: Business Development.

ABSENSI DAN PENGUKURAN
- Check-in mencatat kehadiran.
- Sesi menjadi TUNTAS jika check-in tercatat dan tiga checklist (materi, praktik, refleksi) selesai.
- Isi durasi aktual sesuai waktu yang benar-benar digunakan dan simpan link/screenshot hasil sebagai bukti.
- Menu Evaluasi menampilkan kehadiran, ketuntasan, durasi, artefak, dan status mingguan.

DATA DAN SINKRONISASI
- Data absensi tersimpan di browser/perangkat yang digunakan. Tidak ada sinkronisasi cloud otomatis.
- Gunakan Export JSON untuk backup. Gunakan Import JSON pada perangkat lain untuk memindahkan backup.
- Jangan hapus data browser sebelum mengekspor backup.
